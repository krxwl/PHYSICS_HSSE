# Моделирование полёта камня (Задача M1)
В проекте реализована программа, вычисляющая траекторию движения камня, брошенного под углом к горизонту с учётом сопротивления воздуха.

## Требования и установка (Ubuntu)
Для корректной отрисовки графиков убедитесь, что в системе установлен пакет для 
работы с оконными интерфейсами Python, а также создано виртуальное окружение.

1. Установите системную зависимость `tkinter`:
```bash
sudo apt update
sudo apt install python3-tk
```
2. Создайте и активируйте виртуальное окружение:
```bash
python3 -m venv venv
source venv/bin/activate
```

3. Установите необходимые библиотеки для построения графиков и математических вычислений:
```bash
pip install numpy scipy matplotlib
```

## Запуск программы
Запустите главный файл из директории проекта:

```bash
python3 main.py
```

Все необходимые параметры (начальная скорость, угол, масса тела и коэффициент сопротивления) вводятся интерактивно при запуске программы.

## Архитектура проекта
Код реализован в классе `Solver` и разделен на ввод данных, вычисления и построение отображения:

* `read_data()` — считывание начальных условий из стандартного ввода.
* `speed_equation()` — рассчитывает дифференциальные уравнения для модели вязкого трения, возвращает производные координат и скоростей для текущего шага интегрирования.
* `quad_speed_equation()` — рассчитывает дифференциальные уравнения для модели лобового сопротивления, возвращает производные координат и скоростей для текущего шага.
* `get_viscous_resistance_data()` — настраивает условие прерывания расчетов, решает задачу Коши с помощью функции `solve_ivp`.
* `visualise_data()` — строит график (визуализирует полученный массив данных траектории с помощью библиотеки `matplotlib`)

Также в файле `М1 - отчет.pdf` представлен отчет о проекте.
