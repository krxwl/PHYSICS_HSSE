# Моделирование бильярда на реальном столе (задача М4)

Проект моделирует поступательное и вращательное движение твёрдого тела по горизонтальной или наклонной шероховатой плоскости. Численное решение сравнивается с аналитическими формулами, а результаты выводятся в консоль и сохраняются в виде графиков.

Подробный физический отчёт с постановкой задачи, выводами формул и разбором четырёх экспериментов находится в [М4-отчет.pdf](М4-отчет.pdf).

## Структура проекта

| Файл или каталог          | Назначение                                                                                                                                |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **config.py**             | Константы, точность интегрирования, модели тел и параметры четырёх сценариев                                                              |
| **physics.py**            | Уравнения движения, интегрирование через scipy.integrate.solve_ivp, аналитическое решение и вычисление энергетических и моментных невязок |
| **visualization.py**      | Построение графиков скоростей, координат, энергии и момента импульса                                                                      |
| **main.py**               | Последовательно запускает эксперименты, печатает сравнение с теорией и сохраняет графики                                                  |
| **requirements.txt**      | Список внешних библиотек: NumPy, SciPy и Matplotlib                                                                                       |
| **tests/test_physics.py** | Регрессионная проверка аналитического решения, включая смену направления скольжения                                                       |
| **report.tex**            | Основной отчёт по проекту                                                                                                                 |
| **figures/**              | Графики, автоматически созданные при запуске main.py                                                                                      |

## Установка и запуск в Ubuntu

Команды ниже выполняются в терминале Ubuntu. Для установки системных пакетов понадобится пароль пользователя с правами администратора.

### 1. Установите Python и поддержку виртуальных окружений

Обновите список пакетов и установите Python 3, `pip` и модуль для создания виртуальных окружений:

```bash
sudo apt update
sudo apt install python3 python3-pip python3-venv
```

### 2. Создайте окружение и установите зависимости

Виртуальное окружение хранит библиотеки проекта отдельно от системного Python:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

После активации окружения в начале строки терминала обычно появляется `(.venv)`. Установка пакетов выполняется внутри него.

### 3. Запустите программу

Из каталога проекта, при активном виртуальном окружении, выполните:

```bash
python main.py
```

Программа печатает параметры экспериментов, моменты перехода между режимами, численные и аналитические результаты, а также невязки законов энергии и момента импульса. Четыре PNG-графика сохраняются в `figures/`; повторный запуск обновляет их.

Чтобы позднее запустить проект снова, откройте терминал, перейдите в каталог `M4` и активируйте окружение командой `source .venv/bin/activate`. Когда работа закончена, окружение можно выключить командой `deactivate`.

## Сценарии

Параметры сценариев находятся в словаре `SCENARIOS` файла `config.py`.

1. Удар по центру шара на горизонтальном столе: переход от скольжения к качению.
2. Удар с сильным обратным вращением: шар разворачивается и затем катится назад.
3. Бросок шара вверх по наклонной плоскости: проскальзывание сменяется чистым качением.
4. Проверка перехода между скольжением и чистым качением при разных коэффициентах трения; сравнение ускорений полого и сплошного цилиндров.

Фактор момента инерции задаётся как $beta = I / (m * R^2)$. В конфигурации есть сплошной шар ($beta = 2/5$), сплошной цилиндр ($beta = 1/2$), тонкостенная сферическая оболочка ($beta = 2/3$) и тонкостенный полый цилиндр ($beta = 1$).

## Модель и ограничения

Считается, что тело однородное, осесимметричное и жёсткое; движение плоское; сопротивлением качению пренебрегаем. При скольжении действует сухое трение Кулона, а при достаточном сцеплении тело переходит к качению без проскальзывания. В расчёте используется интегратор RK45; событие нулевой скорости точки контакта фиксирует переход между режимами.

Точность интегрирования и шаг вывода результатов настраиваются в `config.py`. Это учебная модель, поэтому она не учитывает деформацию сукна и шара, боковое вращение, столкновения с бортами и вариации коэффициента трения.
