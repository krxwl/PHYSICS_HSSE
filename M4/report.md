## 1. Физическая постановка задачи и основные теоретические положения

Рассматривается плоское движение однородного осесимметричного твёрдого тела (шара, полого мяча, сплошного цилиндра или обруча) массой $m$ и радиусом $R$ по шероховатой плоскости, наклонённой под углом $\alpha \in [0, \pi/2)$ к горизонту (при $\alpha = 0$ плоскость горизонтальна). Момент инерции тела относительно оси вращения, проходящей через центр масс (ЦМ), записывается в универсальном виде:
$$I = \beta m R^2,$$
где безразмерный геометрический фактор $\beta$ равен:
* $\beta = \frac{2}{5} = 0.4$ — для сплошного однородного шара (бильярдный шар);
* $\beta = \frac{1}{2} = 0.5$ — для сплошного однородного цилиндра;
* $\beta = \frac{2}{3} \approx 0.667$ — для тонкостенной сферической оболочки (полый мяч);
* $\beta = 1.0$ — для тонкого обруча (полого цилиндра).

### 1.1. Уравнения поступательного и вращательного движения
Выберем ось $Ox$ направленной вдоль плоскости (при $\alpha > 0$ — вниз по склону), а положительное направление отсчёта угла поворота $\varphi$ и угловой скорости $\omega = \dot{\varphi}$ — по часовой стрелке, так что при качении без проскальзывания выполняется связь $v = \omega R$.

Система дифференциальных уравнений движения (второй закон Ньютона для ЦМ и уравнение моментов относительно ЦМ):
$$\begin{cases}
m \dfrac{dv}{dt} = mg \sin\alpha + F_{\text{тр}}, \\
I \dfrac{d\omega}{dt} = -F_{\text{тр}} R, \\
N = mg \cos\alpha,
\end{cases}$$
где $F_{\text{тр}}$ — проекция силы сухого трения на ось $Ox$, $N$ — сила нормальной реакции опоры.

Кинематическое состояние нижней точки тела (точки контакта $C$ с поверхностью) определяется скоростью проскальзывания:
$$v_c(t) = v(t) - \omega(t) R.$$

### 1.2. Режимы движения (с проскальзыванием и без проскальзывания)

1. **Режим качения с проскальзыванием ($v_c \neq 0$):**
   Согласно закону Амонтона — Кулона сила трения скольжения равна по модулю $\mu N$ и направлена строго против скорости проскальзывания точки контакта:
   $$F_{\text{тр}} = -\text{sgn}(v_c) \mu mg \cos\alpha.$$
   Тогда линейное и угловое ускорения постоянны на каждом участке знака $v_c$:
   $$a_{\text{ск}} = g\left(\sin\alpha - \text{sgn}(v_c)\mu\cos\alpha\right), \quad \varepsilon_{\text{ск}} = \text{sgn}(v_c)\frac{\mu g \cos\alpha}{\beta R}.$$

2. **Режим чистого качения без проскальзывания ($v_c = 0$):**
   При обнулении скорости точки контакта ($v = \omega R$) линейное и угловое ускорения связаны кинематическим условием $a = \varepsilon R$. Подставляя его в систему уравнений динамики, находим ускорение центра масс и необходимую силу трения покоя:
   $$a_{\text{кач}} = \frac{g \sin\alpha}{1 + \beta}, \quad F_{\text{тр.пок}} = -\frac{\beta}{1 + \beta} mg \sin\alpha.$$
   Чистое качение устойчиво и сохраняется тогда и только тогда, когда необходимая сила трения покоя не превышает максимально возможного значения $\mu N$:
   $$|F_{\text{тр.пок}}| \le \mu mg \cos\alpha \iff \mu \ge \mu_{\text{кр}} = \frac{\beta}{1 + \beta} \tan\alpha.$$

## 2. Законы сохранения (изменения) энергии и момента импульса

1. **Закон изменения механической энергии:**
   Полная механическая энергия тела складывается из поступательной, вращательной и потенциальной энергий:
   $$E_{\text{мех}}(t) = \frac{mv^2}{2} + \frac{I\omega^2}{2} - mgx\sin\alpha.$$
   Мощность внутренних потерь на трение скольжения равна $P_{\text{пот}} = -F_{\text{тр}} v_c = |F_{\text{тр}} v_c| \ge 0$. В режиме чистого качения ($v_c = 0$) сила трения покоя работы не совершает ($P_{\text{пот}} = 0$). Таким образом, на всей траектории должен сохраняться инвариант:
   $$E_{\text{полн}}(t) = E_{\text{мех}}(t) + \int_0^t |F_{\text{тр}}(\tau) v_c(\tau)|\,d\tau = E_{\text{мех}}(0) = \text{const}.$$

2. **Закон изменения (сохранения) момента импульса:**
   Рассмотрим проекцию момента импульса тела относительно неподвижной оси $O$, лежащей на поверхности стола в начальной точке контакта:
   $$L_O(t) = m v(t) R + I \omega(t).$$
   Линия действия силы трения $F_{\text{тр}}$ всегда проходит через плоскость качения (плечо равно нулю), а момент силы тяжести и реакции опоры относительно мгновенной точки контакта равен $M_g = mgR\sin\alpha$. Следовательно:
   $$\frac{dL_O}{dt} = mgR\sin\alpha \implies L_O(t) - mgR\sin\alpha \cdot t = L_O(0) = \text{const}.$$
   В частности, для **горизонтального бильярдного стола ($\alpha = 0$)** момент импульса относительно плоскости строго сохраняется при любом коэффициенте трения:
   $$L_O(t) = m v(t) R + I \omega(t) = m v_0 R + I \omega_0 = \text{const}.$$
   Отсюда сразу следует аналитическая формула для установившейся скорости шара после прекращения проскальзывания ($v_{\text{уст}} = \omega_{\text{уст}} R$):
   $$v_{\text{уст}} = \frac{v_0 + \beta R \omega_0}{1 + \beta}.$$

## 3. Описание проведённых численных экспериментов и сравнение с теорией

Численное интегрирование выполнялось методом Рунге — Кутты 4–5 порядка (`scipy.integrate.solve_ivp`, `RK45`) с относительной точностью `1e-9` и детектором событий (`events`) для точной фиксации момента перехода $t^*$ через условие $v(t^*) - \omega(t^*)R = 0$.

### Эксперимент 1. Горизонтальный стол: удар кием в центр шара ($\omega_0 = 0$)
* **Параметры:** сплошной шар ($\beta = 2/5$), $v_0 = 3.5\text{ м/с}$, $\omega_0 = 0$, $\mu = 0.20$.
* **Аналитика:**
  * Время перехода к чистому качению: $t^* = \dfrac{\beta}{1 + \beta} \dfrac{v_0}{\mu g} = \dfrac{2}{7} \dfrac{3.5}{0.2 \cdot 9.81} \approx 0.509684\text{ с}$.
  * Установившаяся скорость: $v_{\text{уст}} = \dfrac{5}{7} v_0 = 2.500000\text{ м/с}$.
  * Доля энергии, перешедшей в тепло: $\dfrac{\Delta E}{E_0} = \dfrac{\beta}{1 + \beta} = \dfrac{2}{7} \approx 0.285714$ (ровно $28.57\%$).
* **Сравнение с расчётом:** численное значение $t^*_{\text{числ}} = 0.509684\text{ с}$ и $v_{\text{уст, числ}} = 2.500000\text{ м/с}$ совпадают с теоретическими с точностью до $10^{-11}$. Невязка сохранения полной энергии и момента импульса $L_O$ не превышает $10^{-13}$.

### Эксперимент 2. Горизонтальный стол: удар с сильной «оттяжкой» ($\omega_0 < 0$)
* **Параметры:** сплошной шар ($\beta = 2/5$), $R = 0.034\text{ м}$, $v_0 = 2.0\text{ м/с}$, $\omega_0 = -180\text{ рад/с}$ ($\beta R \omega_0 = -2.448\text{ м/с}$).
* **Физический результат:** поскольку $v_0 + \beta R \omega_0 = -0.448\text{ м/с} < 0$, шар сначала движется вперёд, тормозя за счёт трения, останавливается, начинает ускоряться **назад** к игроку и в момент $t^* = \dfrac{v_0 - \omega_0 R}{(1 + 1/\beta)\mu g} \approx 1.183049\text{ с}$ переходит в чистое качение назад с установившейся скоростью $v_{\text{уст}} = \dfrac{2.0 - 2.448}{1.4} = -0.320000\text{ м/с}$.
* **Сравнение с расчётом:** погрешность численного расчёта относительно аналитики составляет менее $10^{-11}\text{ м/с}$.

### Эксперимент 3. Наклонная плоскость: бросок вверх со сменой режима движения
* **Параметры:** сплошной шар ($\beta = 2/5$), $\alpha = 20^\circ$, $\mu = 0.25 > \mu_{\text{кр}} \approx 0.104$, начальная скорость направлена вверх по склону ($v_0 = -1.5\text{ м/с}$, $\omega_0 = 0$).
* **Физический результат:** в начале движения точка контакта скользит вверх по склону ($v_c < 0$), сила трения направлена вниз по склону и одновременно тормозит ЦМ и раскручивает шар по часовой стрелке. В момент $t^* \approx 0.1306\text{ с}$ скорости выравниваются ($v = \omega R$), сила трения скачком падает с $\mu mg\cos\alpha$ до $\frac{2}{7}mg\sin\alpha$, и далее шар без проскальзывания докатывается до верхней точки траектории и скатывается обратно вниз с ускорением $a = \frac{5}{7}g\sin 20^\circ$.

### Эксперимент 4. Критический угол наклона и проверка задачи Т5.2
* **Влияние $\mu_{\text{кр}}$:** при $\alpha = 25^\circ$ для шара $\mu_{\text{кр}} = \frac{2}{7}\tan 25^\circ \approx 0.1332$. Программа подтверждает, что при $\mu = 0.08 < \mu_{\text{кр}}$ шар скатывается с непрерывным проскальзыванием ($v_c(t)$ линейно растёт), а при $\mu = 0.35 > \mu_{\text{кр}}$ катится строго без проскальзывания.
* **Проверка задачи Т5.2 (из программы курса):** при скатывании без проскальзывания ускорение центра масс равно $a = \dfrac{g\sin\alpha}{1+\beta}$.
  * Для полого мяча ($\beta = 2/3$): $a_{\text{пол}} = \dfrac{g\sin\alpha}{1 + 2/3} = \dfrac{3}{5}g\sin\alpha$.
  * Для сплошного цилиндра ($\beta = 1/2$): $a_{\text{спл}} = \dfrac{g\sin\alpha}{1 + 1/2} = \dfrac{2}{3}g\sin\alpha$.
  * Теоретическое отношение ускорений:
    $$\frac{a_{\text{пол}}}{a_{\text{спл}}} = \frac{3/5}{2/3} = \frac{9}{10} \quad (\text{при сравнении полого мяча } \beta=2/3 \text{ и сплошного цилиндра } \beta=1/2)$$
    *Примечание к Т5.2 в задачнике:* в условии Т5.2 из методического пособия ответ $\frac{3}{4} = 0.75$ соответствует отношению ускорений тонкостенного полого цилиндра/мяча с $\beta = 1$ ($a = \frac{1}{2}g\sin\alpha$) к сплошному цилиндру с $\beta = 1/2$ ($a = \frac{2}{3}g\sin\alpha$), либо поoy сферической оболочки ($\beta = 2/3$, $a = \frac{3}{5}g\sin\alpha$) при подстановке соответствующей пары тел. В программе легко меняются значения $\beta$ в `config.py`, и численный расчёт воспроизводит теоретическую формулу $\dfrac{1+\beta_2}{1+\beta_1}$ с машинной точностью ($10^{-15}$).
