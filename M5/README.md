# Рефакторинг модели физического маятника

## Структура

- `constants.py` — параметры выбранного маятника.
- `model.py` — модель тела, момент инерции, уравнения и энергия.
- `energy.py` — история механической энергии и энергетический баланс.
- `theory.py` — точный нелинейный период, эллиптическое решение и линейная теория затухания.
- `simulation.py` — численное интегрирование и поиск периода по пересечениям равновесия.
- `plotting.py` — построение графиков.
- `physical_pendulum.py` — сценарий исследования: вызывает функции, печатает сводку и показывает графики.

## Запуск

Установить зависимости:

```bash
pip install numpy scipy matplotlib
```

Запуск:

```bash
python physical_pendulum.py
```
